    - `practice.projecth.application.product` (`ProductRepositoryPort`, `ProductUseCase`, `ProductService`)
    - `practice.projecth.application.cart` (`CartRepositoryPort`, `CartUseCase`, `CartService`)
  - **`projecth-infrastructure`**: 데이터베이스 매핑 및 영속화 어댑터 레이어
    - `practice.projecth.infrastructure.persistence.product` (`ProductJpaEntity`, `ProductMapper`, `SpringDataProductRepository`, `ProductRepositoryAdapter`)
    - `practice.projecth.infrastructure.persistence.cart` (`CartJpaEntity`, `CartItemJpaEntity`, `CartMapper`, `SpringDataCartRepository`, `CartRepositoryAdapter`)
  - **`projecth-api`**: 웹 REST 컨트롤러 및 애플리케이션 진입 레이어
    - `practice.projecth.api.product` (`ProductController` 및 DTO 패키지)
    - `practice.projecth.api.cart` (`CartController` 및 DTO 패키지)
    - `practice.projecth.ProjectHApplication` (Spring Boot 실행 메인 클래스)

## 3. ⚙️ 핵심 비즈니스 로직 및 구현 상세
- **상품 상태 자동 전이 정책**: 
  - `Product` 내부에서 재고를 `decreaseStock`하여 잔여량이 `0`이 되면 상품 상태를 자동으로 `OUT_OF_STOCK`(품절)으로 전이시킵니다.
  - 일시 품절 상태에서 `increaseStock`을 통해 재고가 1개 이상 추가되면 자동으로 `ON_SALE`(판매중) 상태로 복구됩니다.
- **장바구니 가격 스냅샷 정책**:
  - `CartItem` 생성 시점의 최신 판매가 정보를 `priceSnapshot` 필드로 보관하여, 향후 실제 결제나 주문 시점과의 가격 차이 비교 등에 대비할 수 있게 설계했습니다.
  - 동일한 상품을 중복하여 장바구니에 다시 담을 경우, 수량은 누적되지만 가격 스냅샷 정보는 담는 시점의 최신 가격으로 새롭게 스냅샷을 갱신합니다.

## 4. 🌐 REST API 명세
### 상품(Product) API
- **상품 등록**: `POST /api/products`
  - 요청 바디: `{ "name": "상품명", "price": 15000, "initialStock": 100, "categoryId": 1 }`
- **상품 상태 수정**: `PATCH /api/products/{productId}/status`
  - 요청 바디: `{ "status": "ON_SALE" }`
- **재고 증가**: `POST /api/products/{productId}/stock/increase`
  - 요청 바디: `{ "quantity": 10 }`
- **재고 차감**: `POST /api/products/{productId}/stock/decrease`
  - 요청 바디: `{ "quantity": 5 }`
- **상품 상세 조회**: `GET /api/products/{productId}`

### 장바구니(Cart) API
- **아이템 추가**: `POST /api/carts`
  - 요청 바디: `{ "memberId": 1, "productId": 1, "quantity": 2 }`
- **수량 수정**: `PATCH /api/carts/{productId}`
  - 요청 바디: `{ "memberId": 1, "quantity": 5 }`
- **아이템 삭제**: `DELETE /api/carts/{productId}?memberId=1`
- **장바구니 조회**: `GET /api/carts?memberId=1`
